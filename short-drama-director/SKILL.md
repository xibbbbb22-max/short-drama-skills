# 短剧导演与分镜

把剧本转成能供制作人员或生成平台使用的镜头方案，保留原故事的冲突、信息揭示顺序和反转。只制作用户需要的部分；已有角色设定、分镜或提示词时，在其基础上修改。

## 确认制作输入

阅读用户提供的剧本及相关设定，确认目标成片时长、画幅、表现形式、已选平台及可复用素材。信息不足且会改变故事表达或交付方式时，只询问关键缺项；非关键参数可以给出标明为建议的方案，不能把建议写成平台限制。

- 只有故事梗概而没有可分镜内容时，说明缺少哪些场次或对白；需要补写完整剧本时使用 `short-drama-writer`。
- 仅在用户明确指向脉脉 13 周年比赛时，读取 [比赛参考](../short-drama-producer/references/maimai-13-competition.md)。比赛时长、赛道和制作期限不作为其他项目的默认硬约束。
- 用户指定平台时，只使用已确认的能力和格式。没有实际证据时，将参考图、口型同步、负面提示词、镜头时长上限等标为待确认，不宣称已接通泡漫或其他平台。

## 建立连续性规范

优先沿用已有编号；新项目可用角色 `C01`、场景 `L01`、镜头 `S001`。编号一旦进入制作就保持稳定，新增镜头分配新编号，显示顺序单独表达。

根据片中实际需要输出精简规范：

- **角色**：固定的年龄感、脸部特征、发型、服装主色和关键道具；情绪和动作作为镜头变量。剧情中确有换装时记录状态及起止镜头，避免每个镜头重新设计角色。
- **场景**：布局、主光方向、时间及必要陈设；明确人物的相对站位、视线和出入方向。
- **画风**：画幅、视觉媒介、色彩、光影和镜头语言。将用户已确认项与待选项分开。
- **参考素材**：记录用户提供的文件或链接及其对应 ID；实际读取后才描述其内容。没有参考图时给出文字规范，不称已有参考图。

## 拆分可制作镜头

以信息变化和情绪节拍拆镜，优先让一个镜头呈现一个主要动作或信息点。复杂多人互动、连续大幅运动或难以保持一致的动作，可提出拆镜、反应镜头、声音先行或道具特写等方案；不要因此改掉关键情节。

镜头表按当前顺序提供下列信息，可以拆成紧凑表格和逐镜头补充，避免一张过宽表格：

| 信息 | 内容 |
|---|---|
| 镜头 ID、预计秒数 | 稳定编号；成片中实际占用的预计时长 |
| 角色／场景 ID | 该镜头实际出镜角色及所在场景 |
| 画面与动作 | 景别、机位、构图、动作起止状态；运镜仅在表达需要时添加 |
| 对白与声音 | 说话者、准确台词、必要的停顿／音效／音乐提示；无对白也要明确 |
| 衔接 | 前后镜头的人物站位、动作或道具状态，必要的转场及声音跨镜关系 |
| 生成约束 | 必须保留的外观、服装、场景状态和不能发生的变化；实际平台限制另行标记 |

让反应、停顿和揭示有明确时长，不能只凭镜头数量推算成片长度。涉及屏幕文字、文件或复杂字幕时，可把文字留给后期叠加，并给出准确文案；用户指定直接生成文字时遵循其选择并说明该镜头需要检查可读性。

## 核对时长与对白

- 列出镜头时长合计、片头／片尾等额外时长、转场重叠量和预计成片时长。转场若已计入镜头就不重复加减；声音跨镜只计算一次。
- 有实际录音时，以录音时长加必要停顿为准。没有录音时，可用中文每秒约 3–5 个口播字作粗估，标明采用的速度，并为笑点、反应和情绪留余量；数字、英文、长停顿另估。
- 对白、动作和停顿超出镜头时长时，指出具体镜头和差额，优先调整镜头分配；若必须删台词或改剧情，给出局部改稿，不悄悄压缩关键信息。
- 总时长超出用户上限时，给出满足上限的可行分镜版本；若保留全部台词与时长要求冲突，明确冲突并让用户选择保留重点。

## 交付平台输入包

按用户需求交付角色／场景规范、分镜表、时长核对和逐镜头提示词。提示词包括该镜头的固定视觉特征、人物与场景、单一主要动作、构图及必要运镜；将对白和音频要求单列，避免混入不支持音频的平台输入。

- 已验证平台支持参考图时，注明该镜头应绑定的素材；不支持或未知时保留可独立使用的文字描述。
- 未获官方格式或现有模板时，使用普通 Markdown 或纯文本逐镜头交付，不臆造 API、参数名称或平台专有导入文件。
- 本工作流产出制作说明与提示词，不自动发起付费生成或上传。用户另行要求角色图、场景图或封面时，可使用已安装的 `imagegen`；视频、配音和剪辑须使用实际可用且适合该任务的工具。
- 将源剧本版本与分镜版本对应起来。只修改部分镜头时，列出修改的 ID、关联前后镜头和时长变化，保留其余已确认内容；需要补拍或重新生成的范围应具体到镜头。

完成前核对：角色／场景 ID 可追溯，镜头动作与对白可容纳，关键道具和站位连续，提示词与分镜一致，总时长计算完整。仅报告实际完成的设计和仍待确认的制作条件，不将方案写成已生成素材或已完成成片。
