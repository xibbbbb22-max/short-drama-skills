# 短剧制片统筹

将目标、已有素材和实际可用工具组织为可执行的制作流程。用户只要求排期或预算时，交付该范围的方案；授权完整制作时，在可用能力内推进到交付。

## 建立制作依据

- 从现有上下文提取目标受众、题材或赛道、目标片长、截止时间、人员与设备、平台、已有资产和生成额度。需求歧义会影响实施时先询问，不重新追问已有答案。
- 用户明确指向脉脉 13 周年比赛时，读取[比赛约束](references/maimai-13-competition.md)。其他制作任务使用用户自己的要求，不套用比赛限制。
- 确认真正可调用的工具及可读取的材料。平台宣传、活动文档与当前 Agent 可执行能力分开记录；没有接口、连接器或已验证的浏览器路径时，不声称已自动操作平台。
- 需要平台操作时先检查其实际输入方式、参考图支持、单次生成限制、配音/字幕功能、导出规格和额度显示。未知项目标记待核实，不能编造 API、按钮、价格或导入格式。

## 组织工作

按当前任务选用所需技能，不默认重做已有成品或运行所有阶段：

| 当前缺口 | 可复用技能 | 交接物 |
|---|---|---|
| 故事或剧本尚未确定 | `$short-drama-writer` | 剧本版本、人物和场景、目标时长 |
| 缺少制作输入与视觉约束 | `$short-drama-director` | 角色/场景规范、镜头表、生成输入 |
| 需要检查剧本、素材或成片 | `$short-drama-review` | 被检查版本、原始素材或可访问成片 |
| 用户需要作品介绍或入围路演 | `$short-drama-pitch` | 已完成作品、实际制作过程和展示要求 |

读取飞书资料可用 `lark-doc`；创建参考图可用 `imagegen`。只在任务需要且环境中可用时调用。生成参考图不代表视频、配音或剪辑能力已经接通。

- 保留已有编号；没有时可用角色 `C01`、场景 `L01`、镜头 `S001`。让镜头、素材文件与对应的剧本版本关联，避免把旧素材误当新版本。
- 用一张制作表跟踪必要状态：镜头/资产、来源版本、依赖、当前状态、输出位置、下一步；仅在有多人协作时增加负责人。
- 剧本、角色设定和分镜存在先后依赖；独立素材在共用设定确定后可以并行。多人操作同一平台账号时，先确认是否会覆盖项目或相互消耗额度。
- 变更一个镜头时只更新受影响的素材和衔接，不自动全片重生成。用户要求改剧情则先更新剧本及受影响的下游版本。

## 控制时间与生成预算

- 根据实际剩余时间倒排交付，给导出、完整播放和必要修复保留时间；以尽早拿到可播放粗版为中间目标。各阶段时长是估计，按平台实际等待时间更新。
- 定额已知时记录计费单位、剩余额度、计划首次生成开销和返工余量。没有可靠计费数据时使用“待核实”的条件预算，不伪造 token 数或假定每个镜头成本相同。
- 首次生成、失败重试、局部重做分别记账。复用已合格资产，优先修复影响理解、关键角色连续性、声音或交付的问题。
- 不无限重试。达到用户设定的额度或尝试上限、进入导出缓冲时间，或同一错误连续出现两次时停止同一路径重试，依据已有结果换可行路径或报告阻塞。
- 收费生成仅在用户授权的制作与额度范围内进行，不自动购买额度或切换付费套餐。创建这些 skill 本身不触发生成或平台付费操作。

## 交付状态

交付可访问的实际成片位置、已核验项目和残留问题。只有提示词、剧本或导出方案时明确说明当前完成到哪一步，不将其标为成片。

若缺少平台执行能力，完成可制作的输入包，并给出基于已验证界面的最短人工交接步骤；界面也未验证时只列待确认入口与所需输入，不编造操作步骤。
